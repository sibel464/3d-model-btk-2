# Trilocale Milano — 3D Ev Turu

Milano, Via Boncompagni'deki bir dairenin 3D modelini kullanan, scroll ile gezilen interaktif web sitesi (Vite + Three.js).

## Çalıştırma

```bash
cd web
npm install
npm run dev   # http://localhost:5173
```

## Klasörler

| Klasör / Dosya | İçerik |
|---|---|
| `web/` | Web sitesi kaynak kodu (ayrıntılar `web/README.md`) |
| `trilocale_via_boncompagni_milano.glb` | Modelin tek dosyalık GLB sürümü |
| `trilocale_via_boncompagni_milano-gltf/` | glTF + dokular |
| `trilocale-via-boncompagni-milano-3ds/` | Orijinal 3ds kaynağı ve dokular |
| `Trilocale_Via_Boncompagni_Milano.usdz` | USDZ (AR) sürümü |
